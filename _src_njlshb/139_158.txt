回转阶梯式孔板格栅清污机
产品详情
回转阶梯式孔板格栅清污机（也称 &ldquo;阶梯网板格栅 / 孔板阶梯格栅&rdquo;）是一种细精度、强防缠绕、大通量、全自动的固液分离设备，核心为阶梯状不锈钢冲孔板 + 上部回转驱动，专门解决传统耙齿格栅易缠毛发纤维、易卡堵、维护量大的痛点，是市政污水厂、泵站及纤维类工业废水预处理的主流细格栅设备。
一、适用场景
市政污水厂 / 雨水泵站进水渠细格栅（替代传统回转耙齿格栅）
自来水厂取水口、电厂循环水、工业园区废水预处理
纺织、造纸、食品、屠宰等含大量纤维 / 毛发 / 细小塑料的工业废水
河道治理、景区水景、餐厨 / 养殖污水精细过滤
二、工作原理
拦截过滤：设备倾斜安装（70&deg;&ndash;75&deg;），污水流经阶梯孔板栅面，水从孔中穿过，毛发、纤维、塑料袋、细小悬浮物被截留在孔板表面。
回转提升：上部驱动电机带动链轮链条，牵引孔板组自下而上连续回转，截留杂物随阶梯孔板平稳上升。
自清卸渣：孔板转到顶部时重力翻转 + 旋转毛刷 / 高压反冲洗，杂物自动落入集渣槽；孔板表面光滑无耙齿缝隙，纤维毛发无法缠绕，实现持续自清。
密封防漏：机架两侧配橡胶滑移密封，防止杂物旁漏；水下无传动部件，仅孔板接触污水，故障率低。
三、核心结构与材质
机架：304/316L 不锈钢，箱板式结构，强度高、抗变形，适配 1.0m 水位差工况。
孔板栅面（核心）：304/316L 不锈钢板激光冲孔，孔径 1&ndash;20mm（常用 3/5/6mm）；阶梯式排列，过水面积比平面格栅大 30%+，通量大、水头损失小（&le;350mm）。
传动系统：上部驱动（电机 + 减速机 + 链轮链条），水下无轴承 / 传动件，仅孔板接触污水，腐蚀与故障风险低；配扭矩限制器，过载自动停机保护。
清渣装置：顶部旋转毛刷 + 高压反冲洗喷嘴（水压&ge;0.4MPa），确保孔板不挂渣、不堵塞，孔板再生率&ge;85%。
控制系统：PLC 智能控制，支持手动 / 定时 / 液位差自动三种模式，可对接远程中控，无人值守运行。
四、关键优势（对比传统回转格栅）
✅ 防缠绕：光滑孔面无耙齿缝隙，毛发纤维无处可缠，解决长期痛点。
✅ 大通量低阻：阶梯孔板过滤面积大，同等占地过水能力提升 30%+，雨季不壅水；过栅流速 0.6&ndash;1.0m/s，水头损失小。
✅ 高可靠性免维护：水下无传动件，故障少、维护量降 60%+，使用寿命&ge;15 年。
✅ 分离精度高：孔径 1&ndash;20mm 可选，拦截细小悬浮物，拦截效率&ge;98%，保护后续水泵 / 设备。
✅ 防腐耐用：全不锈钢材质，适配酸碱 / 高盐污水，长期水下不变形。

六、配套设备
可搭配无轴螺旋输送机、栅渣压榨机、集渣斗，实现捞渣&rarr;输送&rarr;脱水一体化，减少二次污染。
